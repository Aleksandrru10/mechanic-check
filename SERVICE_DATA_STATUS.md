# Состояние данных по автомобилям

Проверено 30 сентября 2026 года. Версия приложения: 1.88.

## Объём задачи

Пользователь подтвердил первый этап: актуальные легковые модели России для JETOUR, TENET, FAW/BESTUNE и CHERY. Для каждой нужны состав ТО-1 — ТО-8, заменяемые детали, допуски и объёмы моторного масла, жидкостей коробки и агрегатов полного привода, а также интервалы их замены. Значения должны относиться к выбранному двигателю, коробке и приводу.

В [каталоге TENET](https://tenet.ru/models/) перечислены 6 моделей, в [каталоге JETOUR](https://jetour-ru.com/models) — 6, включая T1 Гибрид с предзаказом, в [каталоге BESTUNE](https://bestune.ru/) — 3, в [каталоге CHERY](https://www.chery.ru/models/) — 3. Все 18 названий есть в приложении. FAW и BESTUNE используют один набор данных легковых моделей. Дополнительно сохранены 9 ранее добавленных моделей российского рынка; всего 27 разных моделей, а не 32 с учётом повторения FAW/BESTUNE.

Наличие модели и работающих восьми кнопок ТО не доказывает полноту её технических данных. Оценка остатка в процентах без проверки всех строк не используется как критерий завершения.

## Доказательства, необходимые для завершения

1. Каждая требуемая строка имеет официальный источник, страницу/таблицу, код двигателя или агрегата и применимость к российской версии.
2. Все заменяемые детали и жидкости из ТО-1 — ТО-8 показаны на соответствующих интервалах; учтены более ранние сроки по времени и тяжёлым условиям.
3. Пользователь может выбрать известную модификацию; её карточка и чек-лист не показывают чужие агрегаты. Неизвестный код явно требует определения, а не получает случайное значение.
4. Проверка через форму охватывает все различающиеся типы силовых установок; структурный проход по функциям дополняет её и не заменяет сверку с источниками.
5. Подписанный APK опубликован, установленный клиент получает правильный latest.json, размер и SHA-256 APK проверены на GitHub Raw.

До закрытия этих пунктов задача остаётся незавершённой. Пробелы в документации не заполняются цифрами от похожей модели.
