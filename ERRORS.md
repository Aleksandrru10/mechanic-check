# Подтверждённые ошибки проекта

Этот файл фиксирует мои ошибки, их причины и проверку исправления. Перед изменением формы, регламентов или публикацией APK нужно прочитать относящиеся к работе записи. Добавлять сюда только подтверждённые случаи.

## 2026-09-29 — приложение перестало находить обновления

- **Симптом:** установленная версия 1.36 сообщала, что новые версии не обнаружены, хотя APK были опубликованы на GitHub.
- **Моя ошибка:** начиная с выпуска 1.39 и до 1.60 я записывал `latest.json` с полями `file` и `bytes` вместо `apk` и `size`, а также удалил обязательные `schema`, `packageName` и `minSdk`. Я проверял доступность файла и SHA-256, но не сверял JSON с кодом `UpdateActivity.fetchRelease()` установленной версии.
- **Исправление:** восстановил формат `latest.json` для 1.60, затем выпустил 1.61 с правильным форматом. Добавил `release.py prepare` и `release.py verify`, а в `AGENTS.md` записал обязательные поля и порядок проверки после `git push`.
- **Подтверждение:** код версии 1.36 требует эти поля; `release.py verify` принимает 1.61; GitHub Raw отдал корректный JSON и APK; пользователь подтвердил, что приложение обновилось.
- **Правило:** перед каждым выпуском проверять схему `latest.json` по старому установленному клиенту и запускать `python release.py verify`. HTTP 200 для JSON и APK без проверки полей не доказывает работоспособность обновления.

## Ранние версии — поля формы JETOUR оставались видимыми

- **Симптом:** после выбора JETOUR и регламентного ТО поля «Что делаешь» и «Название работы» по-прежнему показывались.
- **Причина:** CSS-правило Android WebView переопределяло скрытие элементов; затем потребовалась синхронизация состояния формы при выборе марки и ТО.
- **Исправление:** версии 1.14–1.16 изменили начальную разметку и обработчики формы; версия 1.16 исправила CSS-правило. Подтверждённое описание — в `ROADMAP.md`.
- **Правило:** изменения видимости полей проверять в Android WebView, а не только по состоянию JavaScript или в обычном браузере.

## Версия 1.17 — повторный запрос автомобиля после выбора марки и модели

- **Симптом:** после выбора JETOUR, модели и ТО приложение требовало заполнить отдельное поле «Автомобиль».
- **Причина:** проверка создания работы продолжала требовать свободный текст, хотя марка и модель уже были выбраны.
- **Исправление:** при известной марке название автомобиля формируется из марки и модели; отдельное поле остаётся для «Другой марки». Подтверждённое описание — в `ROADMAP.md`.
- **Правило:** проверять полный пользовательский путь от выбора марки до создания чек-листа.
