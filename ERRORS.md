# Подтверждённые ошибки проекта

Этот файл фиксирует мои ошибки, их причины и проверку исправления. Перед изменением формы, регламентов или публикацией APK нужно прочитать относящиеся к работе записи. Добавлять сюда только подтверждённые случаи.

## 2026-09-29 — приложение перестало находить обновления

- **Симптом:** установленная версия 1.36 сообщала, что новые версии не обнаружены, хотя APK были опубликованы на GitHub.
- **Моя ошибка:** начиная с выпуска 1.39 и до 1.60 я записывал `latest.json` с полями `file` и `bytes` вместо `apk` и `size`, а также удалил обязательные `schema`, `packageName` и `minSdk`. Я проверял доступность файла и SHA-256, но не сверял JSON с кодом `UpdateActivity.fetchRelease()` установленной версии.
- **Исправление:** восстановил формат `latest.json` для 1.60, затем выпустил 1.61 с правильным форматом. Добавил `release.py prepare` и `release.py verify`, а в `AGENTS.md` записал обязательные поля и порядок проверки после `git push`.
- **Подтверждение:** код версии 1.36 требует эти поля; `release.py verify` принимает 1.61; GitHub Raw отдал корректный JSON и APK; пользователь подтвердил, что приложение обновилось.
- **Правило:** перед каждым выпуском проверять схему `latest.json` по старому установленному клиенту и запускать `python release.py verify`. HTTP 200 для JSON и APK без проверки полей не доказывает работоспособность обновления.

## Ранние версии — поля формы JETOUR оставались видимыми

- **Симптом:** после выбора JETOUR и регламентного ТО поля «Что делаешь» и «Название работы» по-прежнему показывались.
- **Причина:** CSS-правило Android WebView переопределяло скрытие элементов; затем потребовалась синхронизация состояния формы при выборе марки и ТО.
- **Исправление:** версии 1.14–1.16 изменили начальную разметку и обработчики формы; версия 1.16 исправила CSS-правило. Подтверждённое описание — в `ROADMAP.md`.
- **Правило:** изменения видимости полей проверять в Android WebView, а не только по состоянию JavaScript или в обычном браузере.

## Версия 1.17 — повторный запрос автомобиля после выбора марки и модели

- **Симптом:** после выбора JETOUR, модели и ТО приложение требовало заполнить отдельное поле «Автомобиль».
- **Причина:** проверка создания работы продолжала требовать свободный текст, хотя марка и модель уже были выбраны.
- **Исправление:** при известной марке название автомобиля формируется из марки и модели; отдельное поле остаётся для «Другой марки». Подтверждённое описание — в `ROADMAP.md`.
- **Правило:** проверять полный пользовательский путь от выбора марки до создания чек-листа.

## Версия 1.66 — подробная карточка T77 перекрывалась старой

- **Симптом:** при выборе FAW/BESTUNE T77 показывалась краткая карточка с данными нескольких двигателей вместо подробной карточки российской версии 1.5T.
- **Причина:** после присваивания подробной карточки в `mechanic.js` оставалось более позднее присваивание того же ключа из старой версии приложения.
- **Исправление:** в версии 1.67 удалено позднее присваивание; для обоих названий марки используется подробная карточка.
- **Проверка:** сценарии ТО-1 — ТО-8 для T77 проходят, а проверка исходника подтверждает отсутствие перекрывающего присваивания.
- **Правило:** после обновления данных модели проверять все присваивания её ключа и итоговую карточку в интерфейсе.

## Версия 1.67 — объёмы 8AT ошибочно относились к 6AT T99

- **Симптом:** карточка T99 показывала 5,5 / 6 л для обеих автоматических коробок.
- **Причина:** объёмы из раздела спецификации руководства для 8AT были скопированы также в строку 6AT, где указан только тип жидкости AW-1.
- **Исправление:** в версии 1.68 добавлен выбор коробки; объёмы показаны только для 8AT SS-VIII-L, у 6AT AW-1 прямо отмечено отсутствие данных о сервисном объёме.
- **Проверка:** сверены таблица на стр. 139 официального руководства и карточки обеих коробок; варианты ТО-1 — ТО-8 проходят проверку.
- **Правило:** в таблицах с несколькими агрегатами сверять границы каждой строки и не переносить ёмкость на соседнюю модификацию.

## Версия 1.68 — ошибочное топливо и общая проверка коробки X50

- **Симптом:** карточка JETOUR X50 указывала бензин не ниже АИ-95; при добавлении подробного ТО финальная проверка для версии с 5MT первоначально выводила пункты роботизированной коробки.
- **Моя ошибка:** прежняя карточка была составлена без сверки с руководством X50, а условие финальной проверки определяло тип коробки по модели и названию операции, не учитывая выбранную силовую установку.
- **Исправление:** в версии 1.69 указан АИ-92 и выше по руководству JETOUR X50; добавлен выбор 1.5/5MT и 1.5T/6DCT, а проверки DCT показываются только для 6DCT.
- **Проверка:** сверены страницы 176–178 официального руководства X50 и карта ТО официального дилера; автоматическая проверка прошла для обеих комплектаций и ТО-1 — ТО-8.
- **Правило:** технические значения сверять с руководством конкретной российской модели; условные пункты финальной проверки испытывать на каждой комплектации, в том числе там, где пункт должен отсутствовать.

## Версия 1.70 — объём бака X70+ из старой таблицы

- **Симптом:** карточка актуального российского JETOUR X70+ показывала бак 55 л.
- **Моя ошибка:** значение из старой таблицы жидкостей было перенесено в карточку текущей модели без сверки с актуальной модельной страницей JETOUR Россия.
- **Исправление:** в версии 1.71 указаны 57 л по актуальной российской модельной странице; различие со старой таблицей объяснено в карточке.
- **Проверка:** сверены модельная страница JETOUR Россия и таблица из прежнего руководства; карточка и создание чек-листа проверены для всех вариантов кода коробки.
- **Правило:** при обновлении модельного года сверять идентификаторы и объёмы не только с руководством, но и с актуальными российскими комплектациями; расхождения источников явно отмечать.

## Версия 1.73 — старый код двигателя в карточке DASHING AWD

- **Симптом:** карточка общей модели показывала для текущей 1.6T/8AT/AWD объём масла 4,3 ± 0,2 л по старому SQRF4J16, хотя актуальное руководство различает SQRF4J16 и SQRF4J16C.
- **Причина:** данные старой версии двигателя были объединены с текущей комплектацией без выбора силового агрегата.
- **Исправление:** в 1.74 добавлен выбор 1.5T/6DCT и 1.6T/8AT/AWD. Подтверждённые объёмы 1.5T оставлены в её карточке; для SQRF4J16C старый объём убран до сверки по VIN.
- **Проверка:** сопоставлены актуальная модельная страница и официальные руководства DASHING; оба варианта ТО-1 — ТО-8 и путь создания чек-листа прошли проверку.
- **Правило:** буквенный суффикс кода двигателя считать отдельной модификацией и не переносить объём масла без подтверждения для неё.

## Версия 1.74 — переднеприводная ёмкость в карточке T9

- **Симптом:** карточка и чек-лист российского TENET T9 показывали объём ATF для 2WD наряду с AWD.
- **Причина:** в руководстве приведены оба варианта коробки, но официальный старт продаж и текущая российская модель относятся к полноприводной машине.
- **Исправление:** в 1.75 из данных T9 убрана ёмкость 2WD; для AWD оставлены 6,6 ± 0,2 л как справочная ёмкость, фактический объём определяется процедурой.
- **Проверка:** сопоставлены руководство T9 и официальное сообщение TENET о старте продаж; проверены ТО-1 — ТО-8 и карточка модели.
- **Правило:** перед переносом всей таблицы руководства сверять, какие модификации реально продаются в России.

## Версия 1.75 — роботизированная коробка в чек-листе T77 с МКП

- **Симптом:** T77 можно было выбрать без указания коробки, и на ТО-7 предлагалась замена жидкости 7DCT, хотя у ранее продававшейся версии есть 6MT.
- **Причина:** из руководства были взяты обе трансмиссии, но отдельный чек-лист T77 был составлен только для 7DCT.
- **Исправление:** в 1.76 добавлен выбор 7DCT/6MT; замена жидкости и калибровка робота теперь условны.
- **Проверка:** сопоставлены официальный список комплектаций и руководство T77; обе трансмиссии проверены для ТО-1 — ТО-8, создан чек-лист 6MT ТО-7 в интерфейсе.
- **Правило:** если руководство содержит несколько коробок, регламент и жидкости должны зависеть от реально выбранной коробки.

## Версия 1.76 — объём масла ARRIZO 8 при несовпадении кода двигателя

- **Симптом:** приложение предлагало 4,3 ± 0,2 л моторного масла для текущего ARRIZO 8.
- **Причина:** в характеристиках официального руководства и на текущей модельной странице указан SQRF4J16C, но таблица жидкостей того же руководства подписана SQRF4J16 без C. Я перенёс объём из таблицы в текущую версию без проверки этого расхождения.
- **Исправление:** в 1.77 из активной карточки и ТО убраны неподтверждённые объёмы моторного масла и охлаждающей жидкости для C. Код текущего двигателя и необходимость сверки по VIN показаны явно.
- **Проверка:** сопоставлены страницы 261 и 267 официального руководства с текущей модельной страницей; проверены ТО-1 — ТО-8 и создание ТО-6 в интерфейсе.
- **Правило:** проверять код двигателя в таблице жидкостей и в технических характеристиках одного руководства, а затем сверять его с текущей российской моделью.

## Версия 1.76 — переднеприводная ёмкость в карточке TIGGO 9

- **Симптом:** карточка и ТО текущего TIGGO 9 показывали вариант заправки ATF для 2WD.
- **Причина:** обобщённая таблица руководства была перенесена целиком, хотя российская модельная страница показывает только AWD.
- **Исправление:** в 1.77 оставлена справочная ёмкость 8AT AWD 6,6 ± 0,2 л и указана проверка фактического объёма по процедуре.
- **Проверка:** сверены текущие комплектации на официальном сайте CHERY и ТО-1 — ТО-8.
- **Правило:** для текущей модели показывать только продаваемые комплектации; архивные варианты отделять, если они нужны.
